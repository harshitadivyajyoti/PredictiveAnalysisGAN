# NO2 Level Analysis and GAN Distribution Learning

## Assignment Objective
This project is part of "Assignment-2: Learning Probability Density Functions using data only." The primary objective is to learn an unknown Probability Density Function (PDF) of a transformed random variable using a Generative Adversarial Network (GAN). Unlike standard statistical approaches, this project assumes no parametric form (e.g., Gaussian, Exponential) for the distribution. The GAN must implicitly model the probability density solely from data samples.

## Problem Statement & Mathematical Transformation
The analysis focuses on Nitrogen Dioxide ($NO_2$) concentration levels, denoted as feature $x$. Before training, the data is transformed into a new variable $z$ using a specific non-linear function derived from a university roll number.

### Transformation Function
Each value $x$ is transformed into $z$ using the equation:
$$z = Tr(x) = x + a_r \sin(b_r x)$$

Where the coefficients $a_r$ and $b_r$ are determined by the student's roll number $r$:
- $a_r = 0.5 \times (r \mod 7)$
- $b_r = 0.3 \times (r \mod 5 + 1)$

### Implementation Specifics
In this specific implementation (Notebook `predanalysispdf2.ipynb`), the following parameters were used:
- **Roll Number ($r$)**: 102317208
- **Calculated $a_r$**: $0.5 \times (102317208 \mod 7) = 0$
- **Calculated $b_r$**: $0.3 \times (102317208 \mod 5 + 1) = 1.2$
- **Resulting Transformation**: Since $a_r = 0$, the transformation simplifies to $z = x$.

## Project Workflow
The project follows a three-step process as defined in the assignment requirements:

1.  **Data Transformation**: Load the raw air quality data and transform the $NO_2$ feature ($x$) into the target variable ($z$) using the formula above.
2.  **PDF Estimation (GAN)**:
    -   **Generator**: Takes random noise ($error \sim N(0,1)$) and outputs synthetic samples ($z_f$).
    -   **Discriminator**: Distinguishes between real samples ($z$) and fake samples ($z_f$).
    -   **Goal**: Train the Generator until the distribution of $z_f$ matches the unknown distribution of $z$.
3.  **Approximation & Visualization**: Use Kernel Density Estimation (KDE) to plot and compare the probability densities of the real data versus the generated data.

## Dataset
The project uses the "India Air Quality Data" dataset.
- **Source**: Kaggle (India Air Quality Data)
- **Feature Used**: $NO_2$ concentration
- **Locations**: Includes data from stations such as Hyderabad, Andhra Pradesh.

## Model Architecture

### Generator
- **Input**: Random noise vector (dimension 1)
- **Hidden Layers**: Two linear layers with 32 neurons each, using ReLU activation.
- **Output**: Single continuous value approximating $z$.

### Discriminator
- **Input**: Single value (real $z$ or fake $z_f$)
- **Hidden Layers**: Two linear layers with 32 neurons each, using ReLU activation.
- **Output**: Probability score (0 to 1) using Sigmoid activation.

## Usage
1.  Ensure `no2data.csv` is present in the working directory.
2.  Run the Jupyter Notebook `predanalysispdf2.ipynb`.
3.  The notebook will:
    -   Load and clean the dataset.
    -   Apply the mathematical transformation (based on the hardcoded roll number).
    -   Train the GAN for 3000 epochs.
    -   Output the loss values for the Generator and Discriminator.

## Results
The final output is a visualization titled "PDF Learned Using GAN," which displays the overlap between:
1.  **Real z (unknown PDF)**: The KDE of the actual transformed data.
2.  **GAN Estimated PDF**: The KDE of the synthetic data generated by the network.

A close alignment between these two curves demonstrates that the GAN has successfully learned the underlying probability density function of the transformed variable.
